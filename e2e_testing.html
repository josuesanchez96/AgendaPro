1. Reserva Exitosa de Cita en Modo Cliente
BDD Gherkin booking_flow.yaml PASSED

📜 Especificación Gherkin

Característica: Reserva de Servicios
  @e2e @reserva @exitoso
  Escenario: Reserva exitosa de una cita desde el flujo de Cliente
    Dado que el usuario inicia la aplicación en "Modo Cliente"
    Y se encuentra en la pantalla de "Selección de Sede"
    Cuando selecciona la sede "Sede Central Polanco"
    Y elige al profesional "Dr. Carlos Mendoza"
    Y selecciona el servicio "Corte Executive & Barba"
    Y elige la fecha "2026-10-05" y el horario "10:30"
    Y completa su nombre "Carlos Eduardo" y teléfono "5512345678"
    Y presiona el botón "Revisar Reserva"
    Y confirma la información presionando "Confirmar y Registrar Cita"
    Entonces la aplicación muestra el mensaje "¡Tu cita ha sido agendada con éxito!"

🤖 Script Maestro (`e2e/booking_flow.yaml`)

appId: com.agendapro.app
---
- launchApp
- assertVisible: { id: "screen-location-title" }
- tapOn: { id: "btn-select-location-loc-1" }
- assertVisible: { id: "screen-professional-title" }
- tapOn: { id: "btn-select-professional-pro-1" }
- assertVisible: { id: "screen-service-title" }
- tapOn: { id: "btn-select-service-srv-1" }
- tapOn: { id: "date-chip-2026-10-05" }
- tapOn: { id: "time-chip-10:30" }
- tapOn: { id: "input-client-name" }
- inputText: "Carlos Eduardo"
- tapOn: { id: "input-client-phone" }
- inputText: "5512345678"
- tapOn: { id: "btn-continue-confirmation" }
- tapOn: { id: "btn-confirm-booking" }
- assertVisible: { id: "confirmation-success-msg" }

2. Gestión en Dashboard del Profesional (Cancelación)
BDD Gherkin professional_dashboard.yaml PASSED

📜 Especificación Gherkin

Característica: Gestión de Citas
  @e2e @dashboard @profesional
  Escenario: Visualización y cancelación de cita en el Dashboard
    Dado que existe una cita confirmada para "Carlos Eduardo"
    Cuando el usuario cambia al "Modo Profesional"
    Entonces la cita aparece en el listado ordenado cronológicamente
    Cuando el profesional presiona el botón "Cancelar Cita"
    Entonces el estado de la cita cambia a "CANCELADA"

🤖 Script Maestro (`e2e/professional_dashboard.yaml`)

appId: com.agendapro.app
---
- launchApp
- tapOn: { id: "btn-mode-pro" }
- assertVisible: { id: "screen-dashboard-title" }
- tapOn: { id: "btn-filter-confirmed" }
- tapOn: { id: "btn-cancel-appointment-apt-101" }
- tapOn: { id: "btn-filter-cancelled" }
- assertVisible: { id: "appointment-card-apt-101" }

📜 Especificación Gherkin

Característica: Validaciones de Formulario
  @e2e @reserva @validacion
  Escenario: Validación de campos requeridos
    Dado que el usuario está en la pantalla de "Fecha, Hora y Datos"

---

- assertVisible: { id: "error-validation-message" }
