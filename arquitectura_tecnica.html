📦 2. Stack Tecnológico y Librerías

React Native + Expo SDK 52

Framework base multiplataforma de alto rendimiento con TypeScript estricto habilitado.

Zustand

Gestión de estado global ligera, sin boilerplate de Redux, ofreciendo actualizaciones reactivas y síncronas.

React Navigation

Navegación fluida y estructurada entre el flujo cliente por pasos y el panel profesional.

Maestro (`maestro.dev`)

Framework de automatización E2E declarativo mediante archivos YAML alineado a escenarios BDD Gherkin.

🧠 3. Patrones de Diseño Aplicados

  • Single Source of Truth (SSOT): Unificación de todas las entidades (Sedes, Profesionales, Servicios, Citas) dentro de un único store de Zustand (`useAppStore.ts`), permitiendo que el Dashboard del Profesional refleje inmediatamente las citas agendadas por el Cliente.
  • Modular Screen Step Pattern: El flujo de reserva está fragmentado en 5 componentes de pantalla desacoplados. Cada pantalla es responsable de su validación y delega la transición al orquestador `AppNavigator`.
  • Deterministic TestIDs for Automation: Cada botón, card, campo de texto e indicador visual cuenta con un atributo `testID` estático y predecible (e.g. `btn-select-location-loc-1`, `input-client-name`), facilitando la ejecución robusta de pruebas E2E sin flakiness.
  • Continuous Native Generation (CNG): Cumplimiento estricto con las directrices de Expo SDK moderno; la configuración nativa se administra 100% mediante `app.json` sin alterar manualmente las carpetas `android/` o `ios/`.
